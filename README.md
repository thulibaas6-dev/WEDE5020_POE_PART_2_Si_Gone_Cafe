# WEDE5020_POE_PART_2_Si_Gone_Cafe
Si Gone Cafe Web Development Proposal and Website Files 

* I removed all inline HTML styles (Colors,alignment,widths) to enforce proper CSS cascading.
* I Created the external STYLE_1.css file to globally apply the blue/yellow theme, Aptos font, and sticky navigation.
* I built a responsive 3-column CSS grid layout for the Gallery and Services pages.
* I implemented picture and srcset tags to ensure gallery images scale responsibly across different screen sizes like tablets, smartphones and desktops.
* I changed the logo and the video to match the theme of my website even better. 
* Fixed lecturer feedback: Corrected relative image paths and adjusted video overlay contrast.
